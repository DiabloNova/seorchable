# مدل کنترل دسترسی مبتنی بر نقش (RBAC) و امنیت سازمانی

امنیت داده‌ها و تفکیک دسترسی‌ها یکی از ارکان اساسی پلتفرم سئورچبل است. در این مستند، ساختار مدل حاکمیتی کنترل دسترسی مبتنی بر نقش (RBAC) توضیح داده می‌شود.

---

## ۱. درختواره نقش‌ها و سطوح دسترسی (Role Hierarchy)

در پلتفرم سئورچبل، سه سطح نقش اصلی تعریف شده است:

1. **مدیر ارشد سیستم (Super Admin):** دسترسی کامل به پیکربندی کل سامانه، تعریف سازمان‌های جدید، ویرایش سهمیه‌ها و پایش بلادرنگ لاگ‌های خطای زیرساخت.
2. **مدیر مستأجر / سازمان (Workspace Admin):** مدیریت کاربران و دسترسی‌های درون همان سازمان، پایش اسناد خزش‌شده، ثبت دامنه‌ها و مشاهده فاکتورهای پرداخت.
3. **بیننده عادی (Viewer):** دسترسی صرفاً خواندنی به داشبورد، گراف دانش، تحلیل احساسات و خروجی گزارش‌های PDF بدون امکان تغییر در تنظیمات.

---

## ۲. نحوه اعتبارسنجی در API

سرویس امنیتی به صورت خودکار توکن‌های ارسالی را در هدرهای HTTP بررسی کرده و از طریق کلاس `TenantContextManager` هویت کاربر و سطح دسترسی او را تطبیق می‌دهد:
```typescript
// نمونه شبه‌کد اعتبارسنجی نقش در پلتفرم
if (!hasPermission(session.user, "workspace_admin")) {
  throw new UnauthorizedException("دسترسی غیرمجاز به منابع سازمانی");
}
```
