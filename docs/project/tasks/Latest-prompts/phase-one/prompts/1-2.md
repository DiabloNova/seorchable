### 1-2: Reconcile the pnpm dependency manifest
```Read the root AGENTS.md first.

Task: Make the declared dependency manifest match production imports.

Inspect:
- `package.json`
- `pnpm-lock.yaml`
- All production imports under `src/`
- `drizzle.config.ts`
- Existing scripts

Add only packages that production code actually imports and that are missing from `package.json`. Remove only packages proven to be unused. Use pnpm only. Do not upgrade Next.js, React, TypeScript, or any dependency unless required to repair the manifest.

Do not modify application source files, schemas, migrations, or lockfile entries manually.

Verification:

pnpm install --lockfile-only
pnpm install --frozen-lockfile
pnpm exec tsc --noEmit
pnpm lint
pnpm build
git diff --check

If a package appears in the lockfile but is not imported, leave it alone unless removal is clearly safe. If the build fails for an unrelated reason, report it without expanding scope.

Final report: every dependency added or removed, why it is needed or safe to remove, and every command exit status.

```
